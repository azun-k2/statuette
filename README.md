# Statuette downloads

Website for **Statuette**, served by GitHub Pages at
https://azun-k2.github.io/statuette/, and the release downloads for
**Statuette Sensors**, the companion helper for the Mac App Store version.

| Page | What it is |
|---|---|
| `index.html` | The app: what it shows, alerts, privacy. The listing's marketing URL and the app's About link point here. |
| `sensors.html` | Statuette Sensors: why, download, install, remove. Linked from Support. |
| `support.html` | Support; the listing's support URL. |
| `privacy.html` | Privacy policy; the listing's privacy URL. |

The app's source lives in a separate repository.
